# e-plantShopping

## Project Description
e-plantShopping is an online plant shopping web application built using React and Redux. 
The application allows users to browse plants, add them to a cart, update quantities, 
and manage their shopping cart efficiently.

## Features
- View available plants
- Add plants to cart
- Increase and decrease item quantity
- Redux state management
- Responsive UI

## Technologies Used
- React
- Redux Toolkit
- JavaScript
- HTML
- CSS
